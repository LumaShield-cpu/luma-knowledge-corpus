# Reconciliation: "quadrants" vs "pads" terminology (corrected)

**Date:** 2026-09-06
**Author:** Stacey (via reconciliation session)
**Supersedes:** [2026-09-06-quadrants-vs-pads-terminology.md](2026-09-06-quadrants-vs-pads-terminology.md)

## Conflict

See the superseded record for the original conflict description
(extraction items flagging "quadrants"/"pads" as drift, plus
inconsistent usage across sources). The first pass at resolving it
relied on a verbal answer alone ("quadrants is technical, pads is
marketing — both valid") without checking it against a primary source.

Shortly after that record was written,
[sources/docs/lumacanonos-unified-canon-state-v3.md](../sources/docs/lumacanonos-unified-canon-state-v3.md)
was located — the actual pre-reset "Unified Canon State v3" document
referenced secondhand elsewhere in the corpus. It states, repeatedly and
across multiple independent sections of the same document:

> "Pads" is the only valid term. "Quadrants" is deprecated and removed.
> — §7.1, Full Scope Canon Report

> Quadrants → Pads (final)
> — Phase 2, Time-Based Canon Evolution Map

This directly contradicted the dual-scope (technical/marketing) answer
already on record.

## Evidence

Presented the contradiction directly; confirmed that the V3 document is
correct: "quadrants" is not a live technical term today, it is a
deprecated/historical term that predates the terminology lock.

## Resolution

**"Pads" is the sole current term** for the four selectable action
zones around the shield's center, in both technical and public-facing
contexts. "Quadrants" is deprecated — it may still appear in older
source material (pre-v3, or drift generated after the reset event; see
[2026-09-06-full-system-reset-non-authoritative.md](2026-09-06-full-system-reset-non-authoritative.md))
but should not be used going forward and is not a valid alternate
technical name.

## Lesson for this project

A verbal answer, even a confident and specific one, is not itself a
primary source — it's a claim to be checked like any other, per
[CONTRIBUTING.md](../CONTRIBUTING.md)'s "actual current behavior" and
"corroboration over recency" rules. Don't fast-path a reconciliation on
an unverified answer when a checkable primary source might exist and
hasn't been searched for yet.
