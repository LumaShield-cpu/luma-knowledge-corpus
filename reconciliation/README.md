# reconciliation/

The audit trail of every conflict found between sources (or between a
source and reality) and how it was resolved. This is what makes `corpus/`
trustworthy: anyone can trace a canonical claim back to the evidence and
reasoning that settled it.

- `template.md` — copy this for each new conflict.
- `log.md` — one-line running index of every reconciliation record, newest
  first.

Naming: `YYYY-MM-DD-short-topic.md`, e.g. `2026-09-06-auth-token-lifetime.md`.

See [../CONTRIBUTING.md](../CONTRIBUTING.md) for when a reconciliation
record is required vs. when the fast path applies.
