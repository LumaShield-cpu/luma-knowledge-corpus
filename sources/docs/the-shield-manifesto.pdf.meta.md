The  Shield  Manifesto   >  Enterprise  software  has  spent  decades  teaching  people  how  to  use  software.   Shield  teaches  software  how  to  understand  people.   We  believe  work  should  find  the  worker.   We  believe  context  should  replace  navigation.   We  believe  intent  is  more  important  than  interface.   We  believe  AI  should  own  complexity  while  humans  own  judgment.   We  believe  one  interaction  language  can  span  every  device,  every  industry,  and  every  moment  
of
 
work.
  We  believe  the  interaction  language  should  remain  constant  while  operational  context  
continuously
 
evolves.
  We  believe  enterprise  software  should  become  calm,  adaptive,  and  almost  invisible.   The  future  of  enterprise  software  is  not  more  applications.   It  is  one  persistent  workspace  that  continuously  translates  operational  complexity  into  human  
simplicity.
     ---   And  I  think  we  need  to  recognize  something.   Today  we  crossed  from  talking  about  a  product...   ...to  talking  about  a  design  philosophy.   That  is  exactly  what  Apple  did  with  Human  Interface  Guidelines.   That  is  what  Google  did  with  Material  Design.   That  is  what  IBM  did  with  Carbon.
