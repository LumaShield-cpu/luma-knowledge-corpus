# sources/

Raw material pulled in from wherever knowledge about Luma currently lives —
kept as-found, not yet verified. Nothing here should be cited as fact
elsewhere without going through reconciliation first (see
[../CONTRIBUTING.md](../CONTRIBUTING.md)).

## Layout

- `docs/` — old design docs, wikis, READMEs, specs pulled from elsewhere.
- `tickets/` — issue/ticket exports (Jira, Linear, GitHub Issues, etc.).
- `chats/` — decisions or context pulled from Slack/chat threads, emails.
- `code-snapshots/` — excerpts of actual code/config used as evidence of
  current behavior (not a place to mirror the whole codebase).

## Rules

- **Immutable once added.** Don't edit a source file after the fact — if it
  turns out wrong, that's what a reconciliation record is for.
- **Always cite provenance** at the top of the file: where it came from,
  who/what produced it, when it was pulled, and (if known) when the
  original was authored.
- Superseded or dead sources stay here with a note saying so — don't
  delete history, just don't treat them as current.
